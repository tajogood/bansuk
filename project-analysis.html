01 / RESEARCH PORTFOLIO

4개 과제에서 무엇을 배울 수 있는가

확인 질문

핵심 현장자산

필요한 IT

네 과제의 교집합은
‘검사 결과를 행동으로 연결하는 이력’입니다.

농장, 계군, 종란, 이동, 검사, 방역점검이 각자의 엑셀이나 시스템에 따로 있으면 연구는 가능해도 현장 대응 속도를 높이기 어렵습니다. 따라서 새로운 제품은 데이터베이스를 크게 만드는 것부터가 아니라, 실제 업무에서 기록이 끊기는 지점을 연결해야 합니다.

03 / DATA ARCHITECTURE

농장이 아니라 ‘계군과 이벤트’를 연결하는 설계

동일 농장에 여러 계군이 공존하고, 하나의 종란·부화 배치에서 여러 사육농장으로 분기할 수 있으므로 단순한 농장 간 선으로는 추적성이 부족합니다.

① 시설·농장

facility_id
종계장·부화장·사육농장·검사기관 식별

② 계군·배치

flock_id / egg_batch_id / hatch_batch_id
부모-자식 계보와 분할 출고 추적

③ 업무 이벤트

movement_id / sample_id / inspection_id
이동·채취·검사·점검 시점을 기록

④ 검토·조치

reviewer_id / action_id / source_ref
책임자·근거원본·후속 조치·감사 이력

연결필수로 다뤄야 할 관계주의할 점가능한 업무
종계군 ↔ 종란종계군 → 종란 배치, 산란·수집일혼합 수집·복수 부모 관계 고려난계대 질병 역추적
종란 ↔ 부화입란 배치 → 부화 배치 → 병아리 출하분할·합류·폐기·수량 정합성같은 출처의 출하처 탐색
이동 ↔ 시설출발/도착, 차량·시각·수량, 기록 원본계보 연결과 차량접촉 연결은 구분관련 농장 조사 후보 추출
검체 ↔ 계군검체, 계군 ID, 검사법, QC, 판독, 검토자질병·검사법별 판독 기준 차이계보에 따른 검사 이력 조회
점검 ↔ 조치농장 유형, 체크리스트, 증빙, 담당자, 기한매뉴얼 개정 버전 보존점검과 시정조치의 폐회로
↗ 이 데이터 구조를 사용하는 데모 실행
04 / VALIDATED BUILD PLAN

개발 순서는 ‘기존 자산 확인 → 작은 실증 → 통합’

실무 데이터가 없는 상태에서 거대 통합 시스템부터 만들면 과거 연구과제의 시행착오를 반복할 수 있습니다.

STEP 0

과거 산출물 조사

4개 과제의 최종보고서, DB 테이블, 화면, 소스코드, 활용계약, 권한, 실제 사용자 확보 여부 조사

STEP 1

검사·계군 식별 통합

반석 검사실의 실제 샘플을 익명화해 농장·계군·검체 ID를 연결하고 보고서 생성 검증

STEP 2

제한된 계보 추적 실증

협력 종계장 1곳·부화장 1곳·사육농장 여러 곳의 일부 생산·이동 기록으로 역추적 기능 확인

STEP 3

현장 점검·후속 업무 연결

2017년 체크리스트를 디지털화하고 검사 의뢰→점검→조치→재점검이 이어지는지 관찰

성공 기준 예시: 검체와 계군 연결 가능 비율, 이동 원본 누락률, 실제 역추적에 필요한 시간, 담당자의 재입력 건수, 현장 점검 후 미해결 조치 수. 목표 수치는 반석과 실증 데이터 확인 후 정합니다.

05 / FIRST FIELD INTERVIEW

반석에 실제로 확인해야 할 질문

체크한 항목은 이 브라우저에 저장됩니다. 미팅에서 답을 확인하면 체크하세요. 확인 전에는 소프트웨어가 존재하거나 정상 운영됐다고 가정하지 않습니다.

관련 공공서비스는 KAHIS 및 축산물이력제가 이미 있습니다. 외부 연동 가능 여부와 접근 권한은 별도 확인이 필요합니다.
06 / DECISIONS

이번 협업의 방향 제안

기존 제안서의 6가지 사업 아이템을 버리는 것이 아니라, 독립적으로 보이던 데모를 하나의 농장·계군·검체 데이터 체계 아래 연결하는 것이 목적입니다.

우선 무엇부터 만들 것인가?

반석 검사실에서 이미 보유한 데이터로 작게 검증할 수 있는 검사보고서·검체 업무를 시작점으로 삼고, 동시에 차별화될 수 있는 종계장→부화장→사육농장 계보추적을 한정된 현장 실증으로 검증합니다.

현재 6개 데모는 어떻게 바뀌는가?

검사보고서와 수의사 업무는 공통 검사·계군 ID를 사용하도록 개선합니다. 농장 방역과 건강관리는 현장 FieldOps로 연결하고, 위험지도와 지자체 화면은 검증된 실제 자료와 접근 권한이 확보된 뒤 확장합니다.

AI는 어디에 넣는가?

1차에는 자동 보고서 초안, 이력 연결의 데이터 오류 탐지, 매뉴얼 검색, 방문 기록 정리 등 전문가 검토가 가능한 보조 업무부터 적용합니다. 질병 감염·확산의 실제 예측은 별도 데이터·수의학적 검증 없이는 구현했다고 주장하지 않습니다.
